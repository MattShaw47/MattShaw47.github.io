## The challenge

Volunteer groups need enough structure to coordinate supplies, but heavy case-management software can create more work than it removes. The sample application centers the few facts coordinators need to make and revisit a match.

## The approach

Requests and offers remain distinct records connected by explicit assignments. Clear state labels, an append-only activity history, and restrained permissions help multiple teams collaborate without obscuring who made each decision.
